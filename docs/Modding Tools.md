### xEdit:
Extremely useful tool for viewing, managing, creating, plugins and conflict resolution.
1. Download the latest xEdit release from the xEdit Discord server, in the [xedit-builds](https://discord.com/channels/1215789510953140335/1217194963482316803/1217497030671339700) channel.
2. Extract the archive and place the files inside a folder of your choosing (do not use a UAC protected folder or the game folder).
3. Add xEdit to MO2's executables list by pressing CTRL + E, press the + next to executables, and then clicking Add from file..., then point it to xEdit.exe.
4. Add a new executable in MO2, set the **Binary** path to your xEdit.exe and add the arguments **-FNV -IKnowWhatImDoing**.

### NifSkope:
NifSkope is a tool for opening and editing the NetImmerse file format (NIF) used by FNV and Bethesda's other games. I highly recommend downloading and reading [Bits of NifSkopery](https://www.nexusmods.com/newvegas/mods/76374?tab=description) to understand how the nif structure works.
1. Manually download on Nexus.
2. Extract the archive and place the files inside a folder of your choosing (do not use a UAC protected folder or the game folder).
3. Open NifSkope.exe.
4. At the top click Options > Settings > Resources > Paths tab > Fallout 3 / New Vegas > press **Auto Detect Game Paths**.

### Blender NifTools Addon
An addon for blender allowing you to Import, edit, and export NIF and KF files for New Vegas. Partial support for other Bethesda and NetImmerse/Gamebryo games.

1. Manually download on Nexus.
2. Open blender and press **ctrl + ,** to bring up the Preferences interface.
3. Click the Add-ons tab > press the ⌄ [dropdown arrow in the top-right corner] > Install from Disk


### NIF Preview Updated for Mod Organizer 2
Mod Organizer plugin that support previewing NIF files (3D models).

1. Manually download on Nexus.
2. Extract the archive and place the files Mod Organizer plugins directory (MO2 DIR\plugins).

### Gamesettings profiler:
