- **[Tale of Two Wastelands](https://discord.gg/taleoftwowastelands)** - For the Tale of Two Wastelands mod.

- **[xNVSE](https://discord.gg/EebN93s)** - For NVSE and its plugins, also great for modding info.

- **[NH Arms](https://discord.gg/fbKFv4qpNn)** - Mostly known for ported assets and non-nexus mods.

- **[Sweet Retreat](https://discord.gg/TcFSGgx2sT)** - Sweet6Shooter's discord.

### Guides:
- **[Viva New Vegas](https://vivanewvegas.moddinglinked.com/intro.html)** - A crucial modding guide to create a stable working game and modding environment for New Vegas.
- **[Wasteland Survival Guide](https://wastelandsurvivalguide.com/)** - A quality modding guide for TTW.
- **[New Vegas Visual Renewal](https://salamand3r.fail/new-vegas-visual-renewal)** - A newly revised, refreshed, and more complete visual update guide for Fallout New Vegas and Tale of Two Wastelands.
- **[FNV Performance Guide](https://performance.moddinglinked.com/falloutnv.html)** - Wall's based performance guide that everyone should follow.
- **[Decompression Guide](https://vivanewvegas.moddinglinked.com/decompress.html)** - A guide on how to easily remove the compression flag from plugins to improve performance.
- **[LOD Guide](https://vivanewvegas.moddinglinked.com/lod.html)** - A comprehensive guide on how to generate Object and Terrain LOD with xLODgen.
- **[Bits of NifSkopery](https://www.nexusmods.com/newvegas/mods/76374)** - A collection of notes about the Static or Havoked nif structure and manipulating nif file settings in NifSkope.

### Info:
- **[xEdit](https://moddinglinked.com/xedit.html)** - Introduction to xEdit, which will allow you to understand how plugins work and how you can edit records.
- **[xEdit Video](https://www.youtube.com/watch?v=9kJ7v_VlakU%3E)** - A good video by cloudisms that covers multiple parts of xEdit.
- **[The Method](https://moddinglinked.com/themethod.html)** - Guide on how to use The Method, which is used while creating a modlist in order to patch it properly and hide remaining conflicts that need no intervention.
- **[Safe Modding](https://vivanewvegas.moddinglinked.com/safe-modding.html)** - List of many outdated/dangerous mods and tools.
- **[GECK Wiki](https://geckwiki.com/index.php/Main_Page)** - Community continuation of Bethesda's GECK wiki, maintained by NVSE modders; focused on GECK, scripting and game's inner workings.
- **[Independent Fallout Wiki](https://fallout.wiki/wiki/Fallout_Wiki)** - Fan project focused on maintaining a high-quality, comprehensive and accessible encyclopedia about all aspects of the Fallout games, community and mods.
