FIXED/CHANGED:

  • Changed the BSA decompressing process. You no longer need to redo this step after updating post 1.6
  • Changed any mod requiring YUP to their non-YUP versions
  • Controller should now work properly
  • Stewie Tweaks:
    • Adjusted repair pricing and barter skill adjustments
    • Enabled Repair all confirmation
    • Enabled Crippled legs scale jump height
    • Enabled Critical hit messages list limb
    • Enabled explosion radius buff
    • Turn further whilst seated
    • Changed Agility Scales Speed tweak, 2.5% > 3% to be in line with reload and equip speed changes
  • Increased NPC dodge cooldown from 1s to 2s, lowered dodge speed from 150% to 130%
  • Reload Reloaded:
    • Reduced agility point modifier, 5% > 3% reload and equip speed
  • Fixed the Mercenary Assault Rifle not spawning on NPC's
  • Implemented new ammo types .30-06 used by the and Battle Rifle, Automatic Rifle and Military Sniper Rifle
  • Cleansing Flame moved to Cook-Cook
  • Reduced charisma requirements on a number of dialogues (many required 8)
  • Implemented many weapon rebalances
  • Max level is now back to 50 but with 2 reduced skill points per level
  • Levelling is 33% slower, it was previously around 50%
  • Disabled the trait changes from perkout
  • Base carry weight is now 75
  • Weapon condition now affects the spread of the weapon instead of damage
